# Vendored front-end assets

The flasher page writes firmware to devices over Web Serial, so everything it executes is served from this
origin and pinned in git instead of being loaded from a CDN at view time. The page's Content-Security-Policy
(`update_server/middleware.py`) only allows same-origin scripts, fonts and requests.

| Directory | Source | Version | License |
| --- | --- | --- | --- |
| `esp-web-tools/` | npm `esp-web-tools`, `dist/web/` (unmodified) | 9.4.3 | Apache-2.0 |
| `fonts/montserrat-*` | npm `@fontsource/montserrat`, `files/` (logo font, as in the GaggiMate web UI) | 5.3.0 | OFL-1.1 |
| `gm.svg` | GaggiMate web UI, `web/public/gm.svg` | | |
| `flash.css` | Generated by Tailwind CSS 4.3.5 and daisyUI 5.8.1 from `frontend/flash.css` | | MIT |
| `flash.js` | Written for this page | | |

## Updating esp-web-tools

```bash
npm pack esp-web-tools@<version>
tar -xzf esp-web-tools-<version>.tgz
rm update_server/static/esp-web-tools/*.js
cp package/dist/web/*.js update_server/static/esp-web-tools/
```

The chunk file names contain content hashes, so stale files must be removed. Review the diff before committing.

## Rebuilding the stylesheet

`flash.css` only contains the classes the page uses, so it has to be rebuilt whenever
`update_server/templates/flash.html`, `flash.js` or `frontend/flash.css` change:

```bash
npm ci
npm run build:css        # or: npm run watch:css while editing
```

Commit the result. The themes in `frontend/flash.css` are copies of the GaggiMate web UI's `light` and
`dark` themes, so the page follows the firmware's look; `tests/test_updates.py` fails if the page uses a
class the committed stylesheet does not contain.
